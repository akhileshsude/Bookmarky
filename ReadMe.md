📺 Bookmarky

Bookmarky is a simple web application built using HTML and CSS that helps users track and bookmark their favorite TV shows.
This project was created as my first webpage, focusing on learning the fundamentals of web development, layout design, and styling.

🌐 Live Demo

🔗 https://bookmarky25.vercel.app/

📌 Features
Track your favorite TV shows
Clean and simple UI layout
Fully built using HTML and CSS
Beginner-friendly static webpage
Responsive styling for better viewing
🛠️ Built With
HTML5 – for structuring the webpage
CSS3 – for styling and layout
📖 What I Learned

While building Bookmarky, I learned:

Basic HTML page structure
Using CSS for styling and layout
Organizing elements using divs and sections
Deploying a website using Vercel
🚀 Deployment

This project is deployed on Vercel.
You can access the live version here:

👉 https://bookmarky25.vercel.app/

📂 Project Purpose

The goal of this project was to practice and understand the basics of web development by creating a simple but functional webpage for bookmarking TV shows.
